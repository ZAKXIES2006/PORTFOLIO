Unlike List<T>, which stores elements contiguously in a dynamic array to provide fast $O(1)$ random access, LinkedList<T> consists of non-contiguous LinkedListNode<T> heap objects linked solely by forward and backward pointers, making pointer-based insertions and removals $O(1)$ at the cost of requiring $O(n)$ sequential traversals. Consequently, you cannot use collection expressions like ["Why", "isn't", "it", "possible!!"] because LinkedList<T> lacks a parameterless Add(T) method to bind the items to, nor can you access elements via an indexer like LinkedList[3] because nodes have no contiguous memory addresses for pointer arithmetic, which would make any simulated indexing an intentionally misleading $O(n)$ operation.
